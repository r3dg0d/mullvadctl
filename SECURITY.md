# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues privately to the maintainer (`r3dg0d`) via GitHub Security Advisories
on https://github.com/r3dg0d/mullvadctl when available, or by opening a private channel.

Do **not** open public issues for vulnerabilities that could harm users' privacy or security.

## Scope notes for mullvadctl

Companion CLI helper for Mullvad VPN — never replaces or weakens Mullvad security

This tool is provided as-is under the MIT license. It does not replace professional security
advice. Always verify critical privacy properties independently.
